# Kinloop

Kinloop is a source-driven gift concierge product.

## Core experience

- Log in.
- Import a source bundle.
- Discover people, birthdays, clues, and priority opportunities.
- Edit essentials.
- Reveal gift ideas.
- Approve one gift idea.
- Opt into: "Call me 3 days before."

## Safety boundaries

- No purchase or checkout.
- No payment processing.
- No fulfillment.
- Approval records gift intent only.

## Verification

Run in container:

- `scripts/container-run.sh npm run check`
- `scripts/container-run.sh npm run check:browser`
