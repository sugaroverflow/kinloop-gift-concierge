# Kinloop Design Brief

## Register

product

## Visual Direction

Design serves a focused product workflow. Kinloop should feel like a polished AI operations cockpit for relationship commerce: warm enough for gifting, structured enough for trust.

## Palette

- Use OKLCH colors.
- Favor restrained tinted neutrals with one confident accent.
- Avoid ecommerce blue/yellow/red, beige-heavy palettes, purple-heavy gradients, and dark sci-fi dashboard cliches.
- Use color for state, progress, approval, and key action hierarchy.

## Typography

- Use a system UI stack.
- Keep type scale fixed and product-appropriate.
- Labels and data should be crisp, compact, and highly readable.

## Layout

- First viewport should show the full workflow: Sarah context, AgentMail signal, Codex transformation, and approval state.
- Prefer a cockpit layout with strong spatial grouping.
- No nested cards.
- No landing-page hero.
- No marketplace nav, cart, saved-list, or merchant-handoff affordances.

## Components

- Stable dimensions for workflow panels, option cards, buttons, and status chips.
- Clear loading, error, empty, complete, and approved states.
- Buttons should use a consistent vocabulary and should not resize when labels change.
- Audit trail should be compact and scannable.

## Motion

- Use motion only for import/generation/approval state feedback.
- Keep transitions in the 150-250ms range.

## Imagery

- Final recording path should use committed anime-style portraits and gift assets.
- Until assets are generated, the UI should not rely on remote stock imagery as the main visual identity.
