# Kinloop Design Brief

## Visual lane

Anime command pop: bright contrast, energetic highlights, playful portrait/gift framing, and clean product information hierarchy.

## UX bar

- Product-first consumer feel.
- Main screen: source state, top priority, people rail, reveal action.
- Settings/footer language: connected sources, account, privacy & controls, reminder settings.
- No architecture-console wording in user UI.
